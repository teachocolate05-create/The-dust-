# THE DUST

폐쇄된 지하철 환승역을 복구해 생존 거점을 만드는 포스트 아포칼립스 생존 경영 시뮬레이션 (웹, PC·모바일)

## 현재 버전: MVP + 업데이트 1~5 (기획서 전체 구현)

### 실행 방법

[Node.js](https://nodejs.org) 20 이상이 설치되어 있어야 합니다.

```bash
npm install      # 처음 한 번만
npm run dev      # 개발 서버 실행 → 브라우저에서 http://localhost:3000
```

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발용 실행 (코드 수정이 바로 반영됨) |
| `npm run build` → `npm start` | 배포용 빌드 후 실행 |
| `npm test` | 게임 규칙 자동 테스트 |
| `npm run build:preview` | 설치 없이 열 수 있는 단일 파일 `preview/the-dust.html` 생성 (더블클릭으로 실행) |

### 플레이 방법

**시작 상태**: 출입구 아래 2×2만 열려 있고 나머지는 어둠(미탐색)입니다. 침낭 하나(침상 1개분)로 시작합니다. 급수원·비상 발전실·옛 창고는 게임마다 대합실 안 임의의 위치에 있습니다.

**탐색과 시야**: 열린 곳(출입구와 이어진 통로 + 출입 가능한 방)과 그 상하좌우 한 칸만 보입니다. 잔해를 치워 길을 뚫을수록 주변이 한 칸씩 드러나고, 한 번 본 곳은 지도에 남습니다. 방·전력선·수도관·잔해 정리 지정은 탐색한 곳에만 할 수 있습니다. 봉쇄 구역은 셔터를 열기 전까지 지도에 나타나지 않으며(셔터를 보면 건설 탭에 '봉쇄된 셔터'로 나타남), 열면 구역 전체가 지도에 영구히 드러납니다.

**하루 흐름**: 오전 → 오후 → 야간 (각 구간 행동 3회) → 정비 시간 (건설) → 다음 날

- **행동** 탭: 주변 탐색·자원 수집·식량 확보로 물자를 모읍니다. 행동마다 횟수 1을 씁니다.
- **잔해 정리**: 통로와 맞닿은 잔해 1칸을 치웁니다(행동 1, 자재 +1). 생존자에게 '잔해 정리' 업무를 맡기면 지정한 잔해를 구간마다 치웁니다.
- **직접 수리**: 낮 구간에 시설을 선택하고 `직접 수리` (부품 1, 내구도 +25)
- **구간 종료**: 지도 위 `오전 종료 ▶` → 예상 자원 변화·경고를 확인하고 `진행`. 구간마다 식량·식수 1씩 소비
- **정비 시간**: 야간이 끝나면 시작. 행동 횟수 없이 방·시설을 건설하고 `정비 수리`를 합니다. 끝나면 `N일차 시작 ▶`
- **시설 운영**: 기계(발전기·정수 필터·작업대)는 가동 중 구간마다 자원을 쓰고/만들고 닳습니다. 시설 패널에서 `정지`/`가동`
- **저장 용량**: 자원마다 최대치가 있고 넘치면 버려집니다. 창고·탱크·사물함으로 늘립니다.
- **기반시설** 탭 (정비 시간): 전력선(칸당 자재 1)·수도관(칸당 자재 2)을 드래그로 깝니다. 선이 시설이 차지한 칸이나 바로 옆을 지나면 연결됩니다. 이어진 선 하나가 하나의 망이며, 발전기 전력은 같은 망 안에서만 나눠 씁니다. 정수 필터는 전력선 + 급수원과 이어진 수도관이 모두 필요합니다(급수원 1곳당 원수 8/구간).
- **생존자** 탭: '생존자 수색'(낮 40%, 야간 25%)으로 발견 → 2일 안에 '생존자 구조' → 그날 정비 시간에 수용(빈 침상 필요). 업무(휴식·잔해 정리·자원 수집·식량 확보·시설 관리·제작)를 배정하면 구간마다 결과가 나옵니다. 능력치가 높을수록, 피로가 낮을수록 효율이 좋습니다.
- **피로·건강**: 일하면 피로 +10, 휴식 -20, 밤잠 -40(침상)/-15(바닥). 플레이어는 행동마다 +4, 100이면 행동 불가. 식량·식수를 배급받지 못하면 모두 건강이 줄고, 생존자는 건강 0이면 떠납니다.
- **사건**: 2일차부터 구간이 끝날 때 30% 확률로 사건이 일어납니다 (발전기 고장·급수 오염·식량 부패·창고 침수·부상·환기 이상·생존자 발견·물자 발견·위협 출현). 알림 창과 기록 탭(사건 필터)에서 확인합니다.
- **위협**: 나타나면 외부 행동·업무의 획득량이 줄고 다칠 수 있습니다. '위험 제거' 행동(성공 55%, 야간 35%)으로 없앱니다.
- **장소**: '주변 탐색' 중 장소(편의점·철물점·주유소·공사 현장·의원)를 발견하면 '장소 조사'로 한 번 크게 물자를 얻습니다.
- **게임 오버**: 플레이어 건강이 0이 되면 끝납니다. 시작 화면에서 이어하기/새 게임을 고릅니다.
- **저장 용량**: 기본 식량·식수 10, 건설 자재 40에서 시작해, 출입 가능한 방에 저장 시설을 지을 때마다 늘어납니다 (사물함·선반·식량 보관함·적재대·물탱크, 고급: 대형 저장고·식품 저장 선반·대형 물탱크). 시작 자원은 식량 5, 식수 5, 자재 20.
- **구역 개방** (업데이트 1): 동쪽의 봉쇄 셔터 앞까지 잔해를 치우고 정비 시간에 '셔터 열기'. 동쪽 대합실(버려진 자재 창고) → 동쪽 정비 구역(두 번째 급수원).
- **고급 설비** (업데이트 1): 작업실에 '건설 작업대'를 짓고 전력선을 이으면 대형 저장고·식품 저장 선반·대형 물탱크·고효율 발전기·대형 정수기를 지을 수 있습니다.
- **공동 생활실** (업데이트 1): 식탁이 있으면 쉬는 생존자의 피로 회복 +10.
- **생존자 생활** (업데이트 2): 생존자마다 특성 2개(부지런함·게으름·튼튼함·허약함·낙천적·비관적·사교적·까다로움·손재주·길눈 밝음). 부상(외부 일 불가)·질병(구간마다 건강 감소, 방치하면 악화)은 쉬면 낫고, 의료실 + '치료' 업무(의료 능력치)로 빨리 고칩니다. 사기는 휴식·식탁·친구로 오르고 굶주림·탈진·병·앙숙으로 떨어지며, 30 미만이면 효율 저하, 15 미만이면 떠날 수 있습니다. 하루가 지날 때 다툼·가까워짐·이야기 모임·병 옮음·서로 돕기 같은 생존자 간 사건이 일어납니다.
- **자급자족** (업데이트 3): 농업실에 재배상(전력 1·물 1, 6구간마다 식량 6)이나 버섯 재배상(물만, 9구간마다 식량 4)을 놓고, '농사' 업무로 더 빨리 키웁니다. 공동 생활실 조리대는 식량 소비를 25% 줄이고 사기를 올립니다. '제작' 업무 품목(부품·고체 연료·자재 재활용)을 고를 수 있고, 고급 설비로 자동 재배기·연료 정제기·부품 가공기가 있습니다.
- **외부 세계** (업데이트 4, '지상' 탭): '지상 탐사' 행동으로 지역을 찾고, 정비 시간에 생존자 1~3명을 원정 보냅니다(인원×날 수만큼 식량·식수). 돌아오면 물자와 함께 이웃 지역을 알게 되고, 시장 상인회·병원 공동체·철로 약탈단을 만납니다. 교역·선물·진료는 정비 시간에, 약탈단 습격은 경비실(바리케이드·감시 초소)과 '경비' 업무로 막습니다.
- **사기 회복**: '격려하기' 행동(사기 +8), 정비 시간 특별 배급(하루 한 번, 사기 +12). '치료' 업무는 환자를 지정할 수 있습니다.
- **대규모 생존 도시** (업데이트 5): 승강장 왼쪽 끝 점검 통로로 지하 2층(서쪽·동쪽)을 열고, 옛 변전소를 고치면 연료 없이 전력 25. 축전지(남는 전력 저장·방전), 양수 펌프(급수원 +6). 같은 업무를 계속하면 능력치가 오르고(최대 5, 전문가), '거점' 탭의 장기 목표 13개를 이뤄 최종 목표 '독립 생존 거점'을 완성합니다.
- **건강 회복**: 부상·질병이 없어도 쉬면(생존자 '휴식', 플레이어는 행동을 안 한 구간) 60% 확률로 건강 +1~3, 밤잠에도 확률적으로 +1~2.
- **직접 제작**: 전력이 들어오는 작업대가 있으면 자재로 부품·고체 연료를 만듭니다.

### 건설 조작 (정비 시간)

- **지도 누르기**: 방·시설·타일을 선택해 오른쪽(모바일은 아래) 패널에서 정보를 봅니다.
- **방 만들기**: `건설` 탭 → 방 종류 선택 → 지도에서 드래그(모바일은 시작 칸, 끝 칸을 차례로 탭) → `건설`
- **시설 설치**: 방 선택 → `시설 설치` → 시설 선택 → 방 안을 눌러 위치 지정 → 같은 칸을 한 번 더 누르거나 `설치`. `회전`(PC는 R 키)
- **방 크기 변경**: 방 선택 → `크기 변경` → 위/아래/왼쪽/오른쪽 −/+ → `적용`
- **이동·회전·철거**: 시설 선택 후 패널 버튼 사용. 철거 시 비용의 50% 회수
- `Esc`: 작업 취소 · `개발 현황`: 구현된 기능과 예정 기능 확인 · `새 게임`: 처음부터

```
src/
  app/                 Next.js 페이지와 전체 스타일 (globals.css)
  components/          화면(UI) — 지도, 상단 바, 패널, 작업 안내 바
  game/                게임 핵심 (UI와 분리)
    config/            수치·데이터
    core/              타입, 좌표 계산, 자원 계산
    systems/
      space.ts         방·시설 배치 규칙
      access.ts        통로·출입 판정
      phase.ts         시간 구간 규칙 (건설은 정비 시간에만, 행동은 낮에만)
      time.ts          구간 종료·예상치 계산·다음 날
      actions.ts       행동 실행과 결과
      operation.ts     저장 용량·시설 가동·생산/소비·전력·고장·수리
      network.ts       전력선·수도관 설치와 망 연결 판정
      survivors.ts     생존자 영입·업무·피로·건강
      events.ts        사건·위협·장소·게임 오버
      zones.ts         확장 구역 개방
      life.ts          특성·부상·질병·사기·관계·생존자 간 사건
      world.ts         지상 지역·원정·교역·습격
      goals.ts         장기 목표 판정
      vision.ts        시야(안개)와 탐색 기록
    state/             초기 상태, 상태 변경(reducer), 저장
tests/                 자동 테스트
```

**시스템 충돌 방지 설계**: 건설·배치는 `systems/phase.ts`의 `canModifyBase()`(정비 시간만), 행동은 `isDayPhase()`(낮 구간만)로 판단해 서로 겹치지 않습니다. 무작위 결과는 저장된 시드로 계산해 새로고침으로 결과를 바꿀 수 없습니다. 게임 상태는 `state/reducer.ts`를 통해서만 바뀝니다.
